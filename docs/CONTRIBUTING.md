# Contributing

Read AGENTS.md and the project skill before changing architecture or publishing. Use English commit messages and Portuguese interface copy. Keep changes scoped and describe the observable behavior and verification.

Install with `npm ci`. Use `npm run dev` for local development. Before a code release, run `npm run check`, `npm test`, `npm run build`, `npm run test:e2e`, `npm run security:scan`, and `npm audit`. Install browser test binaries with `npx playwright install chromium` when needed.

Do not commit credentials or personal data. Do not add paid services, real lead collection or corporate assets without the applicable scope/content decision. See the security and source-audit references for boundaries. The conceptual visual assets in this project are original; third-party assets require provenance and license review.
