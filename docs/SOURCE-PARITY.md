## Deliberate differences

The user explicitly requested the official logo and closer content coverage after approving the cinematic redesign. This supersedes the earlier typographic-demo-logo and omitted-institutional-content defaults. The implementation retains the approved visual language instead of copying proprietary scripts or reproducing every original sentence. The visible independent-project notice and noindex remain.

The original cookie acceptance banner is not reproduced because the demonstration does not introduce analytics or non-essential cookies. The source's simulated diagnosis/lead flow is not connected. Prior office addresses are superseded by the user's confirmed address. The source displayed a Facebook name without a verified destination, so no speculative profile link is added. Company videos remain explicitly identified external resources; captions/transcripts and redistribution rights have not been independently verified. The app image is an original concept illustration, not a claimed screenshot of the real app.
